# libs/

Положи сюда jar-файлы Xaero для сборки (они нужны только на этапе компиляции и **не входят в репозиторий и в итоговый мод**).
Put the Xaero jars here for compilation (compile-time only; they are **not** part of this repository or of the built mod).

Нужные файлы / Required files:

- `xaeroworldmap-fabric-26.2-1.47.2.jar`
- `xaerominimap-fabric-26.2-26.6.2.jar`
- `xaerolib-fabric-26.2-1.8.5.jar`

Скачать / Download: [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map), [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap), Xaero's Lib (зависимость / dependency).

Если версии или имена файлов другие, поправь пути в `build.gradle`.
If your versions or file names differ, adjust the paths in `build.gradle`.
